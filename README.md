# UH Sugar Land Student Center
CIS 2336 front-end project by Yousif Al Karadi.

## Run the frontend
Open frontend/index.html in a browser. The site uses plain HTML, CSS, and JavaScript; no package installation or build step is required. Photos are loaded from Unsplash, so an internet connection is needed for the images.

## Pages
- Home: project introduction and featured spaces
- About: proposed rooms and campus information
- Book a Room: client-side booking request validation
- FAQ: expandable answers
- Reference: source and AI-use notes
- Contact: developer contact

## Booking form scope
The form checks required fields, date, time order, and UH email format in the browser. It only displays a demo response. It does not contact a server, check live availability, or confirm a reservation. Those functions belong to the later Node.js/Express backend phase.

Room names are proposed examples from the Phase 1 plan, not an official UH facilities listing. Hours and address are not asserted because they were not included in the plan.

## Project structure
- frontend/ — site pages, stylesheet, and JavaScript
- backend/app.js — official starter placeholder, retained for the server-side phase
